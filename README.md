# Krishnakant Rout | Portfolio

Personal portfolio website built with React, Vite, and Tailwind CSS to showcase my work, client projects, and technical skills.

## Tech Stack

* **Frontend:** React 19, Tailwind CSS v4, Vite
* **Animations:** Framer Motion, Lenis (smooth scroll)
* **Icons:** Lucide React
* **Analytics:** Vercel Analytics
* **Deployment:** Vercel

## Key Features

* Custom cursor and smooth inertia scrolling
* Responsive layout optimized for mobile and desktop screens
* Minimal, typography-focused design with smooth page transitions
* Contact integration and lightweight analytics

## Featured Projects

* [AirLock](https://github.com/sid-1506/AirLock): CLI tool to connect GitHub repositories to a VPS with automated webhooks and deployment routing.
* [Patidar Car Boutique](https://patidarcarboutique.vercel.app/): Brand showcase and inventory portal for a luxury automobile boutique.
* [Ravariya Green Energy](https://ravariya.vercel.app/): Corporate website and catalog for a biomass and clean energy manufacturer.
* [Stuti Girls Hostel](https://stutigirlshostel.vercel.app/): Room inquiry and informational platform for student housing.

## Run Locally

Clone the repository and install dependencies:

```bash
git clone https://github.com/sid-1506/Portfolio-project.git
cd Portfolio-project
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
