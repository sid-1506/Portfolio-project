## 📖 Overview

A modern, high-performance developer portfolio built with **React 19**, **Vite**, and **Tailwind CSS**. Designed with an editorial aesthetic, restrained color palette, fluid micro-interactions, and smooth inertia scrolling to showcase real-world client projects, technical skills, and freelance milestones.

---

## ✨ Features & Highlights

- **🎨 Editorial & Minimalist Visual Identity**:
  - Curated palette featuring Forest Green (`#35604C`), Charcoal (`#242321`), and Off-White (`#F7F6F2`).
  - Typography paired with **DM Sans** for headings/body and **JetBrains Mono** for code accents.

- **⚡ Fluid Micro-Interactions & Parallax**:
  - Smooth page transitions and reveal animations powered by **Framer Motion**.
  - Interactive **Intro Curtain** and restrained parallax effects in the hero section.
  - Interactive **custom cursor** replica with hover dynamics.

- **🌊 Inertia Smooth Scrolling**:
  - Integrated with **Lenis** smooth scroll for frictionless navigation.

- **💼 Real-World Project Showcases**:
  - Interactive project cards highlighting client work, live links, and technical stacks.

- **📱 Responsive & Accessible**:
  - Fully responsive across mobile, tablet, and desktop screens with `prefers-reduced-motion` compliance.

- **🚀 Optimized Production Build**:
  - Fast page loads, sub-second HMR with Vite, and production analytics via Vercel.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/) / [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sid-1506/Portfolio-project.git
   cd Portfolio-project
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview the production build:**
   ```bash
   npm run preview
   ```
